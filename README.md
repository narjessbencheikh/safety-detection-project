# Construction Site Safety Detection

> Real-time detection of safety equipment (helmets & vests) using **YOLOv11** + automated audit reports via **Ollama LLM**

 ![Python](https://img.shields.io/badge/Python-3.8+-blue?logo=python)
 ![YOLOv11](https://img.shields.io/badge/YOLOv11-Ultralytics-purple)
 ![Ollama](https://img.shields.io/badge/LLM-Ollama%20llama3.2-green)



---

## 📌 Overview

This project builds an **automated safety monitoring system** for construction sites.

- 🤖 **YOLOv11** detects helmets, safety vests, and violations in real-time
- 💬 **Ollama (llama3.2:1b)** generates a professional safety audit report from detections
- ⚡ Runs fully **offline** — no cloud API needed

---

## 🎯 Detected Classes

| Class | Description |
|---|---|
| `Hardhat` | Worker wearing a helmet ✅ |
| `NO-Hardhat` | Worker without a helmet ❌ |
| `Safety Vest` | Worker wearing a safety vest ✅ |
| `NO-Safety Vest` | Worker without a safety vest ❌ |
| `Person` | Person detected on site |
| `Mask`, `Safety Cone`, `Machinery`... | Additional site objects |

Trained on [Construction Site Safety Dataset](https://universe.roboflow.com/roboflow-universe-projects/construction-site-safety) — 521 training images, 25 classes.

## 🚀 Getting Started

### Prerequisites

- Python 3.8+
- [Ollama](https://ollama.com) installed on your machine

### Installation

```bash
# Clone the repository
git clone https://github.com/narjessbencheikh/safety-detection-yolov11.git
cd safety-detection-yolov11

# Install dependencies
pip install -r requirements.txt

# Install Ollama model
ollama pull llama3.2:1b
```

### Project Structure

```
safety-detection-yolov11/
├── models/
│   └── best.pt              # Trained YOLOv11 weights
├── data/
│   └── test/                # Test images
├── detect.py                # Detection on single image + LLM report
├── detect_realtime.py       # Real-time detection (webcam/video)
├── train.py                 # Training script (reference)
└── requirements.txt
```

---

## 💻 Usage

### Detect on a single image

```bash
python detect.py --image data/test/your_image.jpg
```

**Output:**
- Annotated image with bounding boxes
- Automated safety audit report generated by Ollama

### Real-time detection (webcam)

```bash
# Start Ollama server first
ollama serve

# Run real-time detection
python detect_realtime.py --source 0

# Or on a video file
python detect_realtime.py --source path/to/video.mp4
```

## 🔄 Pipeline

```
📸 Image / Webcam
       ↓
🤖 YOLOv11 Fine-tuned
   → Detects: Hardhat, NO-Hardhat, Safety Vest, NO-Safety Vest, Person
       ↓
💬 Ollama (llama3.2:1b)
   → Generates professional safety audit report
       ↓
📋 Output: Annotated image + Report
   "2 violations detected — HIGH RISK. Immediate action required."
```
